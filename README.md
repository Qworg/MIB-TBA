# MIB-TBA

Tooling and planning for porting the [tbaMUD](https://github.com/tbamud/tbamud)
world into a content pack for [MIB](https://github.com/Qworg/MIB).

- **`docs/implplan.md`** — the implementation plan: six phases (8–13) to turn the
  tbaMUD world into `packs/tba/`, including the engine prerequisites, the
  data-model extensions, the conversion harness, and the scope decision register.

The target pack stack is `mib-stdlib → mib-classic-rpg → mib-tba` (content in
`packs/tba/`).
